    How to play

    One game of Yahtzee a day, and everybody rolls the same dice.

    1. Each round you get up to three rolls. Select dice to hold them between rolls.
    2. After any roll, choose an empty box on the scorecard. Every box is used exactly once, so after thirteen rounds the game is over.
    3. Score 63 or more in the upper section for a 35-point bonus. Each extra Yahtzee, after scoring 50 in the Yahtzee box, earns 100 more.
    4. An extra Yahtzee must go in its matching upper box if that box is open. Otherwise it's a joker: Full House, Small Straight and Large Straight score in full.

    The same dice for everyone

    Every die position has a set value for each roll of each round. If you reroll the third die on your second roll, you get the same number everyone else did. Your choices are the only difference.

    How you're measured

    Par
    What a computer scores playing the mathematically optimal strategy on today's dice, with no knowledge of rolls to come.
    Perfect
    The highest score possible on today's dice if you knew every roll in advance.
